# [Feat]: 支持导出审计日志为压缩 JSONL 格式

## 背景
随着企业客户接入，安全审计团队需要定期拉取全量调用日志以满足合规审计要求。当前仅支持在 Web 界面按页查看，无法大批量导出，影响安全分析效率。

## 需求
1. 在管理后台“审计日志”页面增加“导出日志”操作按钮；
2. 支持筛选时间范围（最近 7 天 / 30 天 / 自定义范围）；
3. 服务端后台异步流式导出并压缩为 `.jsonl.gz` 格式；
4. 导出就绪后通过通知栏弹窗并提供一次性安全下载链接（有效期 2 小时）。

## 关联 Issue
- **关联需求**：#45 (新增组织级审计日志存储)
- **前置依赖**：#38 (完成 S3/GCS 预签名直传凭证机制)

## 验收步骤
1. 进入管理后台 -> 审计日志；
2. 选择时间范围：最近 7 天，点击“导出”；
3. 观察导出任务进入任务队列，并在 3 秒内收到导出完成通知；
4. 下载 `.jsonl.gz` 文件，解压并执行 `jq .` 验证数据完整性。

## 验收标准
- 10 万条日志导出在 5 秒内完成，内存占用不超过 128MB（采用流式分页读取）；
- 导出的 JSONL 包含 `timestamp`, `actor`, `action`, `resource`, `ip`, `status` 字段且校验通过。
